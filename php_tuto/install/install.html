Installation d'un package serveur web + PHP + MySQL (ou MariaDB)

Installation de WAMP sous Windows

Vous pouvez vous procurer le package WAMP à l'URL http://www.wampserver.com/.

Après installation, l'URL http://localhost (ouverte dans un navigateur sur la même machine) permet d'accéder à la page d'accueil du serveur local.

Le répertoire Web du serveur www est généralement situé dans C:\wamp64 :

  • pour installer le tutoriel sur votre machine, dézippez le simplement et placer le répertoire php_tuto tel que dans le répertoire C:\wamp64\www (le tutoriel sera ainsi accessible à l'URL http://localhost/php_tuto)

L'application phpMyAdmin est accessible à l'URL http://localhost/phpmyadmin

Installation de MAMP sous Mac

Vous pouvez vous procurer le package MAMP à l'URL https://www.mamp.info/en/mac/.

Après installation, l'URL http://localhost (ouverte dans un navigateur sur la même machine) permet d'accéder à la page d'accueil du serveur local.

Le répertoire Web du serveur est généralement nommé htdocs.

  • pour installer le tutoriel sur votre machine, dézippez le simplement et placer le répertoire php_tuto tel que dans le répertoire htdocs (le tutoriel sera ainsi accessible à l'URL http://localhost/php_tuto)

N'oubliez pas de gérer les droits d'accès au répertoire htdocs (et aux fichiers qu'il contient) avec chmod et éventuellement chown.

L'application phpMyAdmin est accessible à l'URL http://localhost/phpmyadmin

Affichage des erreurs dans le navigateur

Pour activer l'affichage de toutes les erreurs PHP dans le navigateur, il faut modifier le fichier de configuration php.ini en fixant :

  • la directive display_errors à la valeur On
  • la directive error_reporting à la valeur E_ALL

Pour localiser le fichier de configuration php.ini à modifier, vous pouvez appeler la fonction phpinfo() dans un script PHP. La ligne "Loaded Configuration File" contient le chemin absolu du fichier de configuration chargé.

Relancez le serveur pour qu'il prenne en compte les modifications du fichier de configuration php.ini.

Installation d'un serveur web apache2 php mariadb phpmyadmin sous Ubuntu

Nous vous proposons d'installer ces applications en ligne de commandes avec le gestionnaire de paquets apt.

Installation proprement dite

Mettre à jour votre système :
# apt update
# apt upgrade

Intallation de LAMP :
# apt install apache2 php libapache2-mod-php mariadb-server php-mysql

À la suite de cette installation, l'URL http://localhost (ouverte dans un navigateur sur la même machine) permet d'accéder à la page /var/www/html/index.html, contenant pas mal d'informations intéressantes.

La plupart des scripts PHP utilisent des modules de PHP pour bénéficier de certaines fonctionnalités. Voici comment installer les modules les plus courants :
# apt install php-curl php-gd php-intl php-json php-mbstring php-xml php-zip php-bcmath

Vous pouvez ensuite éventuellement sécuriser l'installation du serveur MariaDB avec la commande :
# mariadb-secure-installation
Cela permet notamment de donner un mot de passe à l'utilisateur root du serveur de bases de données MariaDB.

Utilisation de l'hôte virtuel par défaut d'Apache pour HTTP

Avec Apache, chaque site ou application web correspond en principe à un hôte virtuel (VirtualHost en anglais). Chaque hôte virtuel est défini par un fichier de configuration indépendant, qu'on trouve ou qu'on crée dans le répertoire /etc/apache2/sites-available/.

L'hôte virtuel par défaut d'Apache pour HTTP a pour répertoire racine /var/www/html et pour fichier de configuration
/etc/apache2/sites-available/000-default.conf. Pour simplifier, vous pouvez utiliser uniquement cet hôte virtuel. Pour cela, il vous suffit de placer dans le répertoire /var/www/html :

  • le répertoire php_tuto (issu de la décompression de l'archive php_tuto.zip) : le tutoriel est alors accessible à l'URL http://localhost/php_tuto

Pour activer l'affichage de toutes les erreurs PHP dans le navigateur, modifiez le fichier de configuration
/etc/apache2/sites-available/000-default.conf en ajoutant les 2 lignes suivantes à la fin de la section <VirtualHost *:80> (juste avant la ligne </VirtualHost>) :
   php_flag display_errors On
   php_value error_reporting 2147483647

Permissions

Par défaut sur Ubuntu, Apache est exécuté par l'utilisateur www-data, qui appartient au groupe www-data. Quand Apache créé un fichier sur l'espace disque (via par exemple un script PHP), celui-ci appartient donc par défaut à l'utilisateur www-data et au groupe www-data. De la même manière, le serveur ne peut accéder qu'au contenu accessible par www-data.
A vous de gérer les droits et les propriétaires et groupes propriétaires des fichiers avec chmod et chown.

phpMyAdmin

Intallation de phpMyAdmin :
# apt install phpmyadmin

Lors de l'installation, il vous sera posé quelques questions auxquelles il faut répondre avec soin. Vous trouverez des informations à ce sujet à l'URL https://doc.ubuntu-fr.org/phpmyadmin

Après installation, l'application phpMyAdmin est accessible à l'URL http://localhost/phpmyadmin

Commandes utiles

Pour lancer, ou arrêter ou relancer Apache :
# systemctl {start|stop|restart} apache2

Pour lancer, ou arrêter ou relancer MariaDB :
# systemctl {start|stop|restart} mariadb

Pour vérifier l'état d'un service (Apache ou MariaDB) :
# systemctl status apache2
# systemctl status mariadb

Pour tester l'ensemble de la configuration d'Apache :
# apache2ctl -t
