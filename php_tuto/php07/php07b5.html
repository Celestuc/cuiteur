Si une erreur se produit au cours de la requête, une exception mysqli_sql_exception est levée et mysqli_query() ne retourne pas. Nous devons traiter cette exception pour agir en conséquence, le plus souvent par l'arrêt du traitement en cours et l'affichage d'un message ou le déroutement vers une autre page.

Une erreur peut avoir généralement 3 causes :

  • la requête contient une faute dans le nom d'un champ, d'une table ou d'une commande SQL (par exemple liPage à la place de liPages, lives à la place de livres, SELET à la place de SELECT, etc)
  • la requête essaye de faire une opération "interdite" (par exemple insérer un enregistrement avec une clé primaire déjà existante)
  • la requête contient des caractères mal protégés qui provoquent une erreur de syntaxe.

Dans les 2 cas, l'échec de mysqli_query() entraîne la levée d'une exception mysqli_sql_exception. Comme cette exception n'est pas traitée, cela engendre l'affichage d'un message d'erreur au milieu de la page, et l'arrêt du script.

Comme les erreurs de connexion, les erreurs qui peuvent se produire lors de l'envoi d'une requête SQL au serveur de bases de données avec mysqli_query() doivent toujours être traitées.

Nous allons donc définir une nouvelle fonction dans notre bibliothèque (bib_fonctions.php). 

//____________________________________________
/**
 * Envoie une requête SQL au serveur de BdD en gérant
 * les erreurs.
 *
 * En cas d'erreur, une page propre avec un message d'erreur
 * est affichée et le script est arrêté. Si l'envoi de la
 * requête réussit, cette fonction renvoie :
 *      - un objet de type mysqli_result dans le cas d'une
 *		  requête SELECT
 *      - true dans le cas d'une requête INSERT, DELETE
 *        ou UPDATE
 *
 * @param   mysqli   $bd     Objet connecteur sur la base de données
 * @param   string   $sql    Requête SQL
 *
 * @return  mysqli_result|bool   Résultat de la requête
 */
function bdSendRequest(mysqli $bd, string $sql):
                       mysqli_result|bool {
    try{
        return mysqli_query($bd, $sql);
    }
    catch(mysqli_sql_exception $e){
        $err['titre'] = 'Erreur de requête';
        $err['code'] = $e->getCode();
        $err['message'] = $e->getMessage();
        $err['appels'] = $e->getTraceAsString();
        $err['autres'] = array('Requête' => $sql);
        bdErreurExit($err);    // ==> ARRET DU SCRIPT
    }
}

Pour envoyer une requête au serveur de BdD, tout en gérant les erreurs qui peuvent se produire lors de l'appel de la fonction mysqli_query(), vous devez toujours utiliser la fonction bdSendRequest().
