Quand on parle d'afficher "quelque chose", c'est en réalité envoyer ce "quelque chose" au navigateur qui va lui réellement en faire l'affichage dans sa fenêtre. Toute mise en forme de ce "quelque chose" doit obligatoirement être faite avec des balises HTML et/ou des règles de style CSS.

    La connaissance de HTML (et dans une moindre mesure de CSS) est un pré-requis absolument nécessaire à l'utilisation de PHP.

    echo

    Prototype : 

     echo(string ...$expressions): void

    Nous avons déjà employé de nombreuses fois l'instruction echo qui est la "méthode" à privilégier pour afficher des informations.

    L'instruction echo accepte autant de paramètres (i.e. les éléments à afficher) que nécessaire. Cela nous permet de ne pas avoir besoin d'utiliser de concaténation pour réaliser les affichages.

    Quelque soit le langage utilisé, les concaténations sont toujours coûteuses en ressources, en particulier mémoire, et doivent donc toujours être évitées quand c'est possible.

    Tous les paramètres effectivement transmis à l'instruction echo sont automatiquement transtypés en string avant l'affichage.
    Par conséquent, il ne faut pas transmettre à l'instruction echo des paramètres du type object ou array. Si on essaie d'afficher un objet avec echo, une erreur fatale arrête le script. Et si essaie d'afficher un tableau avec echo, le résultat du transtypage en string est la chaîne 'Array', et une erreur de type warning est levée.

    Les valeurs des paramètres peuvent être des valeurs littérales, des variables, ou des valeurs de retour de fonctions.

    Exemple : l'instruction echo

    L'instruction echo n'est pas une fonction, mais une construction du langage, ce qui explique pourquoi on n'utilise pas de parenthèses lors de son appel.

    La construction du langage echo ne renvoie rien.

    Ce qui est intéressant avec ces fonctions c'est que les tableaux sont examinés récursivement et que les informations sur les clés et les valeurs sont affichées. Pour que l'affichage des tableaux soit lisible, il faut utiliser les balises html <pre> et </pre>.

    printf()

    Prototype : 

     printf(string $format, mixed ...$values): int

    La fonction printf() envoie au navigateur une chaîne de caractères. Le premier paramètre ($format) à passer à la fonction est une chaîne décrivant le format de sortie. Les paramètres suivants (reçus dans $values) sont les valeurs à afficher. C'est une fonction d’impression formatée, ce qui signifie que les paramètres effectivement transmis, reçus dans $values, sont convertis selon un format particulier (appelé spécification de format) avant son insertion dans la chaîne envoyée au navigateur.
    Cette fonction est la même que celle que l'on trouve dans le langage C par exemple.

    Exemple : 
    print("La date : %02d %02d %d", 20, 3, 2022)

    La chaîne de format, $format, est composé de caractères ordinaires qui sont envoyés tels quels au navigateur, et de spécifications de format débutant par le caractère %.

    Chaque spécification de format décrit le format d'affichage d'un paramètre reçu dans $values.

    Dans l'exemple ci-dessus, la première spécification de format %02d correspond au premier paramètre situé après le format de sortie, c'est à dire l'entier 20. Cette valeur entière 20 est donc convertie en une chaîne de caractères suivant la spécification de format %02d, ce qui donne la chaine '20'. Et cette chaîne est insérée dans le format à la place du premier %02d.
    Idem pour le paramètre suivant, l'entier 20, qui est converti suivant la seconde spécification de format %02d, et pour le dernier paramètre, l'entier 2022, qui est converti suivant la dernière spécification de format %d.

    Chaque spécification de format suit le modèle :
    %[argnum$][flags][width][.precision]specifier
    où les crochets indiquent que l'élément correspond est optionnel.

    Après le caractère %, seul le specifier, est obligatoire : il fixe le type de conversion effectuée.
    Quelques valeurs possibles du specifier :

    %
    : aucun paramètre correspondant, affichage du caractère littéral %.
    b
    : le paramètre est traité comme un entier, le résultat est une chaîne qui le réprésente en binaire,.
    c
    : le paramètre est traité comme un entier, le résultat est un caractère (octet) ayant l'entier pour code ASCII.
    d
    : le paramètre est traité comme un entier, le résultat est une chaîne qui le réprésente en décimal.
    u
    : le paramètre est traité comme un entier non signé, le résultat est une chaîne qui le réprésente en décimal.
    o
    : le paramètre est traité comme un entier, le résultat est une chaîne qui le réprésente en octal.
    x
    : le paramètre est traité comme un entier, le résultat est une chaîne qui le réprésente en hexadécimal (en minuscules).
    X
    : le paramètre est traité comme un entier, le résultat est une chaîne qui le réprésente en hexadécimal (en majuscules).
    f
    : le paramètre est traité comme un float, le résultat est une chaîne qui le réprésente comme un nombre à virgule flottante.
    e
    : le paramètre est traité comme un float, le résultat est une chaîne qui le réprésente en notation scientifique(i.e. 1.2e+2).
    s
    : le paramètre est traité comme une chaine qui est envoyée telle quelle au navigateur.

    argnum est un entier suivi du caractère $ permettant de spécifier la position du paramètre ciblé par la spécification de format.

    width précise un gabarit (ou cadre) d’affichage, c’est-à-dire un nombre minimal de caractères à utiliser. Si le résultat peut s’écrire avec moins de caractères, printf() le complétera d’un nombre suffisant de caractères de remplissage (par défaut des espaces) ; en revanche, si le résultat ne peut s’afficher convenablement dans le gabarit imparti, printf() utilisera le nombre de caractères nécessaires.

    Quelques valeurs possibles pour le drapeau flags :

    • un caractère - demande de justifier l’affichage à gauche au lieu de le justifier (par défaut) à droite, dans le cadre (ou gabarit d'affichage) défini par le champ width
    • un caractère 0, ou n'importe quel caractère précédé d'un guillemet simple, permettent respectivement de fixer, comme caractère de remplissage du cadre, le caractère '0' ou le caractère spécifié.

    Pour les specifier e et f, le champ .precision (un point . suivi d'un entier) permet de spécifier le nombre de chiffres à afficher après la virgule (6 par défaut).

    print()

    Prototype : 

    print(string $expression): int

    La fonction print() envoie son paramètre au navigateur. Elle retourne toujours l'entier 1.

    Le fait que cette fonction n'accepte qu'un paramètre oblige soit à concaténer, soit à appeler la fonction plusieurs fois de suite. Dans tous les cas c'est une perte de temps et de ressources. Préférez toujours echo à cette fonction.
