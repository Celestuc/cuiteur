Remplacer un caractère

    Nous avons vu la fonction substr_replace() qui remplace une chaîne à l'intérieur d'une autre chaîne. PHP fournit aussi la fonction strtr() qui permet de remplacer chaque occurence d'un caractère par un autre.

    Sous une première forme : 

     strtr(string $string, string $from, string $to): string

    la fonction accepte trois paramètres :

    • $string : la chaîne sur laquelle travailler
    • $from : le ou les caractères à remplacer
    • $to : le ou les caractères de remplacement.
    Exemple : remplacement de caractères

    En réalité, la fonction strtr() "travaille" sur les octets, elle remplace octet par octet, ce qui pose des problèmes si des caractères codés sur plusieurs octets sont présents dans les chaînes $from ou $to.

    Exemple : remplacement de caractères (avec erreurs)

    Rappel: le code UTF-8 du caractère 'é' est égal à C3 A9.
    Donc, dans l'exemple ci-dessus :

    • lors du premier appel, seuls les octets égaux à C3 sont remplacés par le caractère 'e' (i.e. par l'octet 65 en hexadécimal). Les octets de valeur A9 dont laissés dans la chaîne résultat, qui n'est donc pas une chaîne UTF-8 valide.
    • lors du 2ème appel, tous les octets valant 65 en hexadécimal sont remplacés par l'octet C3; et tous les octets valant 31 en hexadécimal (code UTF-8 ou ASCII du caractère '1') sont remplacés par l'octet A9.

    On peut aussi appeler la fonction strtr() avec seulement 2 paramètres : 

     strtr(string $string, array $replace_pairs): string
    • $string : la chaîne sur laquelle travailler
    • $replace_pairs : un tableau associatif contenant les paires de caractères à remplacer.

    Ce qui est intéressant avec cette façon d'appeler la fonction, c'est qu'on peut remplacer un caractère (en réalité un octet) par plusieurs, ou plusieurs par un, ou plusieurs par plusieurs.

    Nous verrons en détail dans un prochain chapitre ce que sont les tableaux associatifs dans PHP. Dans un premier temps, voici un exemple qui devrait vous permettre de comprendre facilement :
    array('a' => 'b', 'e' => '1', 'PHP' => 'HTML')
    La fonction PHP array() crée un tableau dans lequel à la clé 'a' correspond la valeur 'b', à la clé 'e' correspond la valeur '1' et à la clé 'PHP' correspond la valeur 'HTML'.

    Exemple : remplacement de caractères

    Nous pouvons donc utiliser sans soucis cette deuxième forme d'appel de la fonction strtr() dans nos scripts encodés en UTF-8.

    Majuscules et minuscules

    Des fonctions permettent de modifier les majuscules et les minuscules dans les chaînes.

    • strtolower() et strtoupper() agissent sur l'ensemble de la chaîne.
    • ucfirst() et ucwords() agissent sur les premiers caractères d'une chaîne, ou des mots dans une chaîne.
    Exemple : majuscules et minuscules

    Evidemment, ces 4 fonctions standards de PHP ne sont pas capables de traiter les caractères codés sur plusieurs octets. Pour les traiter correctement, nous pouvons utiliser les fonctions mb_strtolower() et mb_strtoupper(), appartenant à l'extension mb_string.
