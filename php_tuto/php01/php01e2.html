Dans la plupart des cas, sans paramètres, les fonctions ne serviraient pas à grand chose. Nous allons voir comment définir ces paramètres, leur donner des valeurs par défaut, ou réaliser des fonctions avec un nombre variable de paramètres. Nous verrons également quels sont les différents modes de transmission des paramètres d'une fonction.

    Sans déclaration de type

    Dans le premier exemple que nous avons vu, la fonction afficher() acceptait 3 paramètres formels : $texte , $titre et $coul. 

    function afficher($texte, $titre, $coul) {
  echo '<h3 style="background:', $coul, '">'; 
  echo $titre;
  echo '</h3>';
  echo '<p>', $texte, '</p>';
}

    Dans cet exemple, le type des paramètres formels n'est pas indiqué. Par conséquent, des données de n'importe quel type peuvent être passées comme paramètres effectifs (i.e. effectivement transmis) lors de l'appel de cette fonction : elles peuvent être de tout type scalaire (nombre, chaîne et booléen), de tout type composé (tableau et objet), ou de tout type spécial (ressource et null).

    Nous verrons par la suite qu'il est possible, en PHP, d'indiquer le type des paramètres formels.

    Dans l'exemple suivant la fonction afficher() est modifiée pour qu'elle fonctionne avec un paramètre $coul qui est soit une chaîne de caractères soit un nombre.

    Exemple : paramètres

    Le paramètre effectif (ou passé) peut être la valeur d'une variable, une expression littérale ou la valeur de l'évaluation d'une expression.

    Dans :

    afficher($txt, 'Introduction', 16776960);

    $txt est une variable, 'Introduction' et 16776960 sont des expressions littérales.

    On pourrait aussi utiliser le résultat d'une expression comme ci-dessous :

    afficher($txt, strtoupper('Introduction'), 16776000 + 960);
    Exemple : paramètres

    Depuis PHP 7, si on tente d'appeler une fonction avec un nombre insuffisant de paramètres, une erreur fatale arrête le script.

    Si on appelle une fonction avec trop de paramètres effectifs, les paramètres effectifs excédentaires sont ignorés.

    Exemple : paramètres

    Paramètres avec une valeur par défaut

    Nous pouvons définir des paramètres avec des valeurs par défaut en utilisant la syntaxe $param = valeur_par_défaut.
    valeur_par_défaut doit obligatoirement être une constante, et ne peut être ni une variable, ni un membre de classe, ni le résultat d'un appel de fonction. PHP vous autorise à utiliser des tableaux ainsi que le type spécial NULL comme valeur par défaut.

    Lors de l'appel d'une fonction, si la valeur d'un paramètre ayant une valeur par défaut n'est pas indiquée, alors la valeur par défaut du paramètre est utilisée.

    Par exemple, pour mettre une couleur par défaut dans notre fonction afficher(), on modifie son prototype : 

    function afficher($texte, $titre, $coul = '#FFFF00') {
...
}

    Ainsi, il devient possible d'appeler la fonction afficher() sans lui transmettre de paramètre effectif pour le paramètre formel $coul.

    Quand on appelle la fonction afficher() avec seulement 2 paramètres effectifs comme ci-dessous :

    afficher($txt, 'Introduction');
    • le premier paramètre formel $texte reçoit la valeur contenue dans $txt
    • le deuxième paramètre formel $titre reçoit la chaîne littérale 'Introduction'
    • et le troisième et dernier paramètre formel $coul prend sa valeur par défaut.
    Exemple : paramètres avec valeur par défaut

    C'est la position des paramètres effectivement transmis qui fixe quel est le paramètre formel qui reçoit chaque paramètre effectif. Par conséquent, lors de la définition d'une fonction, les paramètres formels ayant une valeur par défaut doivent être positionnés à la fin de la "liste" des paramètres formels.

    Les arguments nommés

    PHP 8 a introduit la notion de arguments nommés (ou paramètres nommés). Les arguments nommés permettent de transmettre des arguments à une fonction en utilisant leur nom formel, sans utiliser leur position. Ceci :

    • documente automatiquement la signification du paramètre effectivement transmis,
    • permet de transmettre des paramètres effectifs dans n'importe quel ordre (i.e. indépendamment de leur position dans l'en-tête de la fonction),
    • et permet de simplifier les appels des fonctions qui ont pour plusieurs paramètres avec des valeurs par défaut, quand on ne souhaite modifier que la valeur d'un paramètre situé en fin de liste.

    Les arguments nommés sont passés en préfixant la valeur avec le nom du paramètre formel suivi d'un caractère  :  (deux-points).

    Mode de transmission des paramètres

    Par défaut, les paramètres des fonctions sont transmis par valeur. Cela signifie que la fonction, dans le corps de sa définition, travaille sur des copies des variables effectivement transmises. Dit autrement, par défaut, chaque paramètre d'une fonction occupe un espace mémoire distinct de celui occupé par l'éventuelle variable effectivement transmise correspondante.
    Ainsi, par défaut, lorsqu'une fonction est appelée, un nouvel espace mémoire est alloué pour chaque paramètre, et il est initialisé avec la valeur effectivement transmise.

    Par conséquent, par défaut, les modifications des paramètres réalisées dans le corps d'une fonction ne sont pas répercutées sur les éventuelles variables effectivement transmises quand la dite fonction retourne.

    Exemple : mode de transmission par défaut

    Le cas des objets est particulier, il sera traité dans le chapitre qui leur est consacré.

    Transmission de paramètre par référence

    Quand le nom du paramètre formel est précédé du caractère & (ampersand) dans l'en-tête de la fonction, il est transmis par référence :

    Dans ce cas, l'adresse mémoire du paramètre effectif est transmise à la fonction. Aucune copie de la variable effectivement transmise n'est réalisée. Si la fonction modifie la valeur du paramètre, la valeur du paramètre correspondant à l'extérieur de la fonction sera automatiquement modifiée puisque les 2 variables désignent (ou pointent vers) le même emplacement mémoire.
    D'une certaine façon, le passage de paramètres par référence permet de "dépasser" la portée des variables.

    Dans l'exemple suivant, le premier paramètre est transmis par référence, le second l'est par valeur. 

    function uneFonction(&$par_ref, $par_val) { ...
    Le passage d'arguments par référence est uniquement possible si les paramètres effectivement transmis sont des variables. L'appel suivant de la fonction ci-dessus 
    uneFonction('abcd', 1234);
    provoquera une erreur car le premier paramètre effectivement transmis doit être modifiable : ça doit être une variable.
    Exemple : mode de transmission par référence

    Nombre variable de paramètres

    Il est possible d'utiliser la notation  ...  pour désigner un nombre de paramètres quelconque dans l’en-tête d’une fonction. Cette notation (appelée Rest) ne s'applique, si nécessaire, qu'au dernier paramètre. Les paramètres transmis sont alors regroupés dans un tableau.

    Exemple : nombre variable de paramètres

    La fonction count() renvoie le nombre d'éléments contenus dans le tableau $b.

    Quels que soient les paramètres indiqués dans l'en-tête d'une fonction, il est possible d'accéder à l'ensemble des paramètres qui lui sont transmis en utilisant les fonctions :

    • func_get_args retourne les arguments d'une fonction sous forme de tableau
    • func_get_arg retourne un élément de la liste des arguments
    • func_num_args retourne le nombre d'arguments passés à la fonction.
    Exemple : utilisation de func_get_args()
    Exemple : utilisation de func_num_args() et func_get_arg()

    Pour réaliser des fonctions avec un nombre variable de paramètres, il est recommandé d'utliser la notation  ...  dans l'en-tête de la fonction (appelée Rest), plutôt que d'utiliser les fonctions func_get_args, func_get_arg et func_num_args.

    Passage d’un tableau comme liste de paramètres

    A l'inverse, il est également possible d'utiliser la notation  ...  (appelée cette fois-ci Spread) sur un tableau lors d'un appel de fonction. Les valeurs du tableau seront alors transmises comme une liste de paramètres.

    Exercice : fonction calculer

    En utilisant le principe du nombre variable de paramètres, écrivez la fonction calculer() qui affiche le résultat la multiplication ou l'addition des éléments qui lui sont passés en paramètre. Il est convenu que le premier paramètre passé définit l'opération à faire, et qu'il doit être égal à  +  ou à  * . Dans le cas contraire, un message d'erreur est affiché.

    Une solution possible

    Exercice : fonction calculer

    Lors du dernier appel de la fonction calculer(), la valeur booléenne true est comparée à la chaîne '+'. Comme l'opérateur de comparaison d'égalité == réalise une comparaison non stricte, et qu'ici on compare un booléen et une chaîne, une comparaison booléenne est effectuée. Avant de comparer les 2 opérandes, la chaine '+' est convertie en booléen, ce qui donne true (type juggling). Donc la condition true == '+' est évaluée à true.

    Pour corriger ce problème, il suffit d'utiliser l'opérateur de comparaison d'identité === à la place de l'opérateur de comparaison d'égalité ==.
