Rerchercher un caractère ou une sous-chaîne

    Différentes fonctions permettent de faire des recherches de caractères ou de chaînes à l'intérieur d'une chaîne.

    Parmi toutes les fonctions de recherche, les fonctions standards de PHP les plus employées sont :

    • strpos() qui renvoie la position d'une sous-chaîne à l'intérieur d'une chaîne,
    • strrpos() qui renvoie la dernière position d'une sous-chaîne à l'intérieur d'une chaîne,
    • strstr() qui renvoie une partie de chaîne à partir de la position d'une sous-chaîne
    • stristr() est identique à strstr() , mais ignore les différences majuscules/minuscules
    • strrchr() qui renvoie une partie de chaîne à partir de la dernière position d'un caractère à l'intérieur d'une chaîne.

    ATTENTION IMPORTANT

    Toutes les fonctions de recherche retournent FALSE si elles ne trouvent pas ce qu'elles cherchent. Afin d'éviter de confondre le 0 de FALSE et le 0 de la position du premier caractère d'une chaîne, il faut toujours tester le résultat de ces fonctions avec l'opérateur d'identité === et pas avec l'opérateur d'égalité ==.

    Soit le code suivant :

    $x = 'François';
$pos = strpos($x, 'F');

    $pos sera égal à 0, car 'F' est à la position 0 dans la chaîne $x.

    Le test avec l'opérateur d'égalité simple (non stricte) : 

    if ($pos == false) { ...

    ne permettra pas de faire la différence entre le nombre 0 et le booléen FALSE. Le script sera donc faux car il considérera que 'F' n'a pas été trouvé dans 'François'.
    Pour éviter le transtypage automatique (type juggling) de l'opérateur d'égalité simple et bien différencier le booléen FALSE et le nombre 0, il faut tester la valeur de retour de la fonction avec l'opérateur d'identitié : 

    if ($pos === false) { ...

    Chacune des fonctions précédentes dispose de son équivalent dans l'extension mb_string :

    • mb_strpos()
    • mb_strrpos()
    • mb_strstr()
    • mb_stristr()
    • mb_strrchr()

    Conclusions :

    • Les fonctions standards de PHP comme strpos() renvoient le cas échéant une position (ou un indice) en nombre d'octets, alors que les fonctions de l'extension mb_string comme mb_strpos() renvoient le cas échéant une position (ou un indice) en nombre de caractères.
    • strrchr($x, 'ê') renvoie la sous chaîne commençant à partir du dernier octet égal à C3. L'erreur vient du fait que les caractères 'é' et 'ê' ont respectivement comme codes UTF-8 C3 A9 et C3 AA.

    Exercice : tester une adresse e-mail

    Ecrivez la fonction isAdresseMail() qui vérifie qu'une adresse email est composée de :

    • au moins un caractère alphabétique, suivi éventuellement d'autres caractères alphabétiques, avec éventuellement des point (.) des tirets (-) ou des underscores (_) entre 2 caractères alphabétiques.
    • le caractère @
    • au moins un caractère alphabétique, suivi éventuellement d'autres caractères alphabétiques, avec éventuellement des point (.) ou des tirets (-) entre 2 caractères alphabétiques.

    La chaîne ne doit contenir aucun espace.
    Il ne peut y avoir qu'un seul caractère @
    Tous les caractères doivent avoir l'un des codes ASCII suivants :

    • 45 : -
    • 46 : .
    • 48 à 57 : 0 à 9
    • 64 à 90 : @, A à Z
    • 95 : _
    • 97 à 122 : a à z

    Il ne doit pas y avoir plus d'un seul point, tiret ou underscore entre 2 caractères alphabétiques.

    Adresses valides selon les spécifications :

    Exercice : tester une adresse e-mail

    Vous serez sans doute surpris à la lecture du code par l'utilisation de la fonction tester(). C'est une fonction qui se trouve dans la bibliothèque bib_fonctions.php et qui permet comme son nom l'indique de tester si une fonction renvoie le résultat attendu.
    Cette fonction accepte au minimum 2 paramètres :

    • le nom de la fonction à tester, $nomFct, sous la forme d'une chaîne de caractères
    • la valeur de retour de la fonction à tester $attendu

    Les paramètres supplémentaires sont reçus dans le tableau $params et sont transmis à la fonction $nomFct en utilisant la notation Spread.

    Si le résultat renvoyé par la fonction à tester, $nomFct, est identique à celui attendu, le nom de la fonction est affiché en vert. Si ça n'est pas le cas, le nom de la fonction est affiché en rouge.

    /**
 * Testeur de fonction
 *
 * @param string	$nomFct		nom de la fonction à tester
 * @param mixed		$attendu	résultat attendu
 * @param mixed		$params		paramètres à passer à $nomFct
 *
 * @return void
 */
function tester(string $nomFct, mixed $attendu,
                mixed ...$params) : void {
	$nbParams = count($params);
	if ($nbParams == 0) {
		echo '<hr>Il faut au moins un paramètre à transmettre',
		      ' à la fonction "', $nomFct, '".';
		return;
	}

	if (! function_exists($nomFct)) {
		echo '<hr>La fonction "', $nomFct, '" n\'existe pas.';
		return;
	}

	$retour = $nomFct(...$params);

	echo '<hr><span style="color:',
	     ($retour === $attendu) ? 'green' : 'red', '">',
			'<b>', $nomFct, '</b></span>',
			'<br>Paramètre', ($nbParams > 1) ? 's : ' : ' : ';

	for ($i = 0; $i < $nbParams; ++$i) {
		echo '<span style="background-color:#ebebeb; margin:0 5px;">';
		var_dump($params[$i]);
		echo '</span>';
	}

	echo '<br>Attendu : ';
	var_dump($attendu);

	echo '<br>Retourné; : ';
	var_dump($retour);
}
