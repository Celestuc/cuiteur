Les chaînes de caractères sont avec les tableaux un des types de données les plus manipulés dans les scripts PHP. Il faut savoir utiliser les bons guillemets (simples ou doubles) suivant les traitements que l'on veut faire ou ne pas faire sur une chaîne.

    Il y a 4 façons pour inclure une chaîne de caractères comme valeur littérale dans un script :

    • entourer la chaîne avec des guillemets simples
    • entourer la chaîne avec des guillemets doubles
    • utiliser la syntaxe heredoc
    • utiliser la syntaxe nowdoc

    Chacune des solutions différe dans la façon dont elle gére les caractères spéciaux et l'interprétation des variables.

    Les guillemets simples

    C'est la façon la plus simple et la moins "coûteuse" (avec la syntaxe nowdoc) pour délimiter une chaîne de caractères littérale.

    Exemple : 
    $hello = 'Bonjour tout le monde';

    Pour inclure un guillemet simple (apostrophe) dans la chaîne, nous devons le protéger (ou l'échapper) avec un backslash (\).

    Exemple : 
    $hello = 'Bonjour tout l\'monde';

    Dans une chaîne littérale délimitée par des guillemets simples :

    • Quand on double un backslash (i.e. quand on écrit deux backslash de suite), il ne reste qu'un seul backslash dans la chaîne résultante.
    • Il n'est pas possible d'échapper d'autres caractères que l'apostrophe et le backslash. Un backslash placé devant n'importe quel autre caractère sera tout simplement placé tel quel dans la chaîne résultante.
    • Pour placer, dans la chaîne résultante, un backslash devant un guillemet simple ou un autre backslash, il donc nécessaire de le doubler.
    Exemple : backslashs en pagaille

    Recommandation : lorsque vous souhaitez placer un backslash dans une chaîne délimitée par des guillemets simples, je vous recommande, pour des questions de lisibilité, de toujours l'échapper en le doublant.
    Cette recommandation sera également valable pour les chaînes délimitées par des guillemets doubles.

    Les guillemets doubles

    Une chaîne de caractères littérale peut être délimitée avec des guillemets doubles.

    Exemple : 
    $hello = "Bonjour tout le monde";

    La différence entre les guillemets doubles et simples est importante car dans les chaînes entourées de guillemets doubles :

    • les variables sont remplacées par leur valeur,
    • les séquences d'échappement sont interprétées.

    Par exemple, dans le code suivant : 

    $prenom = 'François';
$nom = 'Piat';
$personne = "$prenom $nom";

    la variable $personne contiendra la chaîne de caractère François Piat.

    Les séquences d'échappement suivantes sont interprétées :

    \n
    : provoque un passage à une nouvelle ligne (linefeed, LF ou 0x0A (10) en ASCII)
    \r
    : provoque un retour à la ligne (carriage return, CR ou 0x0D (13) en ASCII)
    \t
    : provoque une tabulation horizontale (HT ou 0x09 (9) en ASCII)
    \\
    : permet d'insérer un backslash
    \$
    : permet d'insérer un caractère $ dans une chaîne entourée par des guillemets doubles
    \"
    : permet d'insérer un guillemet double dans une chaîne entourée par des guillemets doubles

    De plus, il est possible d'insérer directement, dans une chaîne délimitée entre guillemets doubles, des octets dont la valeur est donnée en octal ou en hexadécimal. Pour cela, les valeurs en octal doivent être précédées d'un backslash (\), et les valeurs en hexadécimal précédées d'un backslash et du caractère x (\x).
    Voici quelques notations équivalentes :

    • 'A', "A", "\x41", "\101"
    • 'a', "a", "\x61", "\141"
    • "\n", "\x0A", "\xA", "\012", "\12"
    • "\r", "\x0D", "\xD", "\015", "\15",
    Exemple : guillemets simples et guillemets doubles

    Rappel : l'élément HTML pre (pour PREformatted text) permet de représenter du texte pré-formaté. Le texte contenu dans cet élément est généralement affiché dans une police à espacement fixe. Les blancs (espaces consécutifs, tabulations, sauts de ligne) contenus dans le texte sont affichés tels qu'ils sont dans le code source du document.

    La syntaxe heredoc

    La syntaxe heredoc commence par <<<, suivi d'un identifiant arbitraire, puis de la chaîne de caractères. La séquence se termine par l'identifiant initial, placé en premier sur une nouvelle ligne.

    L'identifiant utilisé doit suivre les mêmes règles que pour le nommage des variables PHP : il ne doit contenir que des caractères alpha-numériques ou _, et commencer par un caractère alphabétique ou _.

    Les séquences d'échappement sont interprétées, et les variables remplacées par leur valeur. Les guillemets simples ou doubles dans la chaîne n'ont besoin d'aucune protection particulière.

    Exemple : syntaxe heredoc

    La syntaxe heredoc peut être utilisée avec facilité pour stocker des chaînes de caractères représentant du code HTML. A l'intérieur de la chaîne, le formattage éventuel du code (saut de ligne, indentation) sera gardé lors de l'affichage du code HTML source de la page résultat, rendant ainsi le code source de cette page plus facilement lisible. Les guillemets (simples ou doubles) employés pour entourer les valeurs des attributs ne poseront pas de problème de protection.

    Exemple : syntaxe heredoc

    La syntaxe nowdoc

    La syntaxe nowdoc est aux chaînes délimitées entre guillemets simples ce que la syntaxe heredoc est aux chaînes délimitées entre guillemets doubles. Un chaîne littérale nowdoc est spécifiée de manière similaire à une chaîne heredoc, mais une chaîne littérale nowdoc n'est pas parsée, ce qui signifie qu'il n'y a ni substitution de variable, ni interprétation des séquences d'échappement dans une chaîne nowdoc (i.e. le caractère backslash est un caractère littéral comme les autres).
    Cette syntaxe est idéale pour embarquer de larges blocs de texte, sans avoir besoin d'échapper quoi que ce soit.

    Une chaine nowdoc commence également par <<<, mais l'identifiant qui suit est entouré de guillemets simples, comme <<<'EOT'. Toutes les règles concernant les identifiants heredoc s'appliquent également aux identifiants nowdoc.

    Exemple : syntaxe nowdoc
