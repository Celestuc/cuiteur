Définir des membres statiques

    Les membres des classes (attributs et méthodes) que nous avons définis jusqu'à présent sont des membres d'instance.

    Cela signifie que chaque instance de la classe dispose de ses propres attributs d'instance. A chaque nouvelle instanciation d'une classe, un nouvel espace mémoire est alloué pour y placer les attributs propres à l'instance nouvellement créée. Comme chaque instance d’une classe possède sa propre copie des attributs d'instance, les valeurs de ces attributs peuvent différer d’un objet à l’autre.

    En PHP, le mot-clé static permet de créer des membres statiques (attributs ou méthodes), appelés également membres de classe.

    Un attribut statique possède une valeur unique qui est partagée entre toutes les instances de la classe. Chaque attribut statique est donc alloué une seule fois par classe, quel que soit le nombre d'instances de la classe. Un attribut statique n’est donc pas une propriété d’une instance mais une propriété de la classe et l’accès à cet attribut ne nécessite pas l’existence d’une instance.

    Une méthode statique ne peut pas être appelée pour une instance particulière de la classe :

    • elle ne peut manipuler que les attributs statiques de la classe et ses propres paramètres;
    • l’appel d'une méthode statique ne nécessite pas l’existence d’une instance de cette classe;
    • elle n’a pas accès ni aux attributs d'instance d'un objet, ni aux méthodes d'instance : on ne peut pas utiliser la pseudo-variable $this dans le corps d'une méthode statique;
    • en revanche, dans le corps d'une méthode statique, on peut appeler les méthodes statiques de la classe.

    Une méthode d'instance, elle, est toujours appelée pour une instance précise. Elle a donc accès aux membres d'instance et aux membres statiques de la classe.

    Pour définir un membre statique, il suffit d'ajouter le mot-clé static, avant le type pour un attribut, ou avant le mot clé function pour une méthode. Remarquez l'initialisation de l'attribut statique au moment de sa définition : elle est nécessaire car on ne peut pas l'initialiser dans le constructeur.

    Syntaxe permettant l'accès aux membres statiques d'une classe :

    • Pour accéder à un membre statique, il faut utiliser l'opérateur de résolution de portée :: (double deux-points).
    • Cet opérateur de résolution de portée doit être précédé :
      • du mot-clé self lorsqu'on se trouve dans le bloc qui définit la classe;
      • et du nom de la classe, ou du nom d'une de ses instances, quand on se trouve à l'extérieur de la définition de la classe.
    • L'opérateur de résolution de portée doit être suivi :
      • pour un attribut, de son nom précédé d'un $,
      • pour une méthode, uniquement de son nom.

      À mon avis, à l'extérieur de la définition de la classe, la syntaxe UneClasse::membre est plus "lisible" que la syntaxe $unObjet::membre, car UneClasse::membre indique bien que l'on souhaite accéder au membre statique membre de la classe UneClasse, alors que l'autre syntaxe indique que l'on souhaite accéder à un membre de l'objet, ce qui pourrait laisser penser, de façon erronée, qu'il s'agit d'un membre propre de l'objet. Je vous conseille donc d'utiliser de préférence la syntaxe UneClasse::membre.

      Dans l'exemple précédent, nous n'avons pas défini de setter pour l'attribut statique nbInstances car son utilisation ne pourrait servir qu'à fausser le nombre d'intances de la classe.

    Définir des constantes

    class UneClasse{
	const UNE_CONSTANTE = 'hello';  //constante public
	private const UNE_AUTRE = self::UNE_CONSTANTE . ' world';
	protected const UNE_TROISIEME = [ 1, 2, 3];
}

    La définition d'une constante de classe se fait avec le mot-clé const. La valeur d'une constante doit être fixée au moment de sa définition; ensuite, elle n'est plus modifiable, et donc elle n'est pas accessible en écriture.

    On ne peut pas indiquer le type d'une constante. De toute façon, ça ne servirait à rien étant donné que, par définition, on ne peut pas la modifier ensuite !

    Les constantes de classe ont, par défaut, une visibilité public.

    Les constantes de classe sont allouées une seule fois par classe, comme les attributs statiques. Toutes les instances d'une même classe se partagent donc chaque constante de classe. L'accès aux constantes de classe se fait donc en utilisant l'opérateur de résolution suivant les mêmes règles que celles présentées ci-dessus pour les membres statiques.

    Lors de sa définition ou de son utilisation, le nom d'une constante n'est jamais précédé du symbole $.

    Par convention, les noms des constantes sont écrits en majuscules. Quand un nom est constitué de plusieurs mots, ils sont sont séparés par un _ (underscore).

    Pour illustrer l'utilisation des constantes, nous allons ajouter un nouvel attribut à la classe Guitare. L'attribut son définira l'acoustique de la guitare, à savoir : acoustique, à résonateur, électro-acoustique, électrique.

    Exercice : constantes de classe

    Reprenez le code de la classe Livre ci-dessous et utilisez des constantes de classe pour gérer les 4 catégories de livre possibles ("Méthode", "Partition", "Biographie" ou "Autre"). 

    class Livre {
	private string $titre;
	private string $auteur;
	private int $pages;
	private float $prix;
	private string $cat;

	// Constructeur
	public function __construct(string $titre, string $auteur, int $pages,
	                            float $prix, string $cat){
        $this->titre = $this->verifChaine($titre, 'titre');
        $this->auteur = $this->verifChaine($auteur, 'auteur');
        if (estEntre($pages, 10, 1000)) {
            $this->pages = $pages;
        } else {
            $this->afficheErreur($pages, 'pages');
        }
        if ($prix >= 0 && $prix <= 1000) {
            $this->prix = $prix;
        } else {
            $this->afficheErreur($prix, 'prix');
        }
        $oks = array('Méthode', 'Partition',
                     'Biographie', 'Autre');
        if (in_array($cat, $oks)) {
            $this->cat = $cat;
        } else {
            $this->afficheErreur($cat, 'cat');
        }
    }

	private function verifChaine(string $val, string $attr) : string {
		$val = trim($val);
		($val == '') && $this->afficheErreur($val, $attr);
		return $val;
	}
	private function afficheErreur(int|float|string $val,string $attr):void{
		exit( "<hr>Valeur '<b>$val</b>' invalide pour
			l'attribut <b>$attr</b>.<hr>");
	}
	public function decrire() : void {
        echo '<h4>Instance de la classe Livre</h4>',
                $this->titre, ' - ', $this->auteur, ' - ',
                $this->pages, ' pages - ',
                $this->prix, ' &euro; - ', $this->cat, '<hr>';
    }
}// Fin de la définition de la classe Livre
