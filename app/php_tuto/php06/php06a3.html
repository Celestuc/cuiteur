    Vérification des données coté serveur

    Quelle que soit la méthode utilisée pour soumettre un formulaire, il est impératif de vérifier les données reçues, d'une part pour que notre site ne plante pas si on ne reçoit pas une donnée attendue ou si on reçoit une donnée inattendue; et d'autre part pour ne pas laisser la porte ouverte à des tentatives de piratage.

    Du côté client, avec HTML et JavaScript, il n'y a malheureusement pas de méthodes sûres qui permettent de vérifier que les valeurs saisies sont correctes et que les valeurs envoyées sont bien celles que l'on attend. Même si la nouvelle version de HTML (HTML5) offre des attributs permettant de définir la validité d'une zone, ils sont dans la réalité peu utilisables puisque maintenant tous les navigateurs offre des outils qui permettent de voir et surtout modifier dynamiquement le code HTML des pages affichées. La validation avec JavaScript n'est pas suffisante non plus car il suffit de désactiver JavaScript dans le navigateur ou avec les outils proposés pour qu'aucune validation ne soit faite.

    Il faut donc mettre en place sur le serveur les procédures qui permettent de valider les informations que l'on reçoit "de l'extérieur" (ie Internet), et ce, quelque soit la provenance de ces informations (formulaires en POST, données en GET, cookies, en-têtes HTTP si on les utilise, etc).

    Deux catégories d'erreurs

    Quand on reçoit une donnée erronée, cela peut être dû à un manque d'information ou d'attention du visiteur. Dans ce cas, il faut informer le visiteur pour qu'il puisse corriger son erreur. En revanche, si l'on a à faire à un visiteur mal intentionné qui cherche à pirater notre site, il faut par exemple le rediriger vers une déconnexion ou le blacklister.

    La distinction entre ces deux catégories d'erreurs est sujette à discussion. Par exemple, si un utilisateur envoie une chaîne avec des balises HTML, on peut considérer qu'il s'agit d'une tentative de piratage, ou bien être plus "tolérant" et simplement l'informer de son erreur, tout en protégeant bien entendu notre site contre les attaques XSS.
    Dans la suite, on va considérer toutes les erreurs détectées, qui nécessitent une modification du code HTML, comme des tentatives de piratage, tout en gardant à l'esprit que notre application doit également fonctionner correctement sur les vieux navigateurs qui ne supportent pas encore les dernières fonctionnalités d'HTML5.
    Exemple : sur les vieux navigateurs qui ne supportent pas encore les input de type number , ils fonctionnent comme des input de type text. Donc, si nous recevons une chaîne non numérique pour l'identifiant, nous informerons simplement le visiteur de son erreur.

    Vérification des clés dans $_POST et $_GET

    Nous allons commencer par vérifier les clés des éléments présents dans $_POST. Pour faciliter cette vérification, nous allons ajouter la fonctionparametresControle() dans notre bibliothéque de fonctions : 

    /**
 * Contrôle des clés présentes dans les tableaux $_GET ou
 * $_POST - piratage ?
 *
 * Soit $x l'ensemble des clés contenues dans $_GET ou $_POST
 * L'ensemble des clés obligatoires doit être inclus dans $x.
 * De même $x doit être inclus dans l'ensemble des clés autorisées,
 * formé par l'union de l'ensemble des clés facultatives et de
 * l'ensemble des clés obligatoires. Si ces 2 conditions sont
 * vraies, la fonction renvoie true, sinon, elle renvoie false.
 * Dit autrement, la fonction renvoie false si une clé obligatoire
 * est absente ou si une clé non autorisée est présente; elle
 * renvoie true si "tout va bien"
 *
 * @param string    $tabGlobal 'post' ou 'get'
 * @param array     $clesObligatoires tableau contenant les clés
 *                  qui doivent obligatoirement être présentes
 * @param array     $clesFacultatives tableau contenant
 *                  les clés facultatives
 *
 * @return bool     true si les paramètres sont corrects, false sinon
*/
function parametresControle(string $tabGlobal,
							array $clesObligatoires,
							array $clesFacultatives = []): bool{
    $x = strtolower($tabGlobal) == 'post' ? $_POST : $_GET;

    $x = array_keys($x);
    // $clesObligatoires doit être inclus dans $x
    if (count(array_diff($clesObligatoires, $x)) > 0){
        return false;
    }
    // $x doit être inclus dans
    // $clesObligatoires Union $clesFacultatives
    if (count(array_diff($x,
						 array_merge($clesObligatoires,
						             $clesFacultatives))) > 0){
        return false;
    }

    return true;
}

    Cette fonction est également utilisable pour vérifier les clés des éléments présents dans $_GET, lors d'une transmission de paramètres dans l'URL.

    Validation des zones numériques

    Pour l'identifiant et pour le niveau sélectionné avec le bouton radio, nous attendons de recevoir des "entiers" dans $_POST['numIdentifiant'] et $_POST['radNiveau'].

    Comme toutes les valeurs des éléments du tableau $_POST sont de type string, nous ne pouvons pas utiliser la fonction is_int() pour tester les valeurs de $_POST['numIdentifiant'] et $_POST['radNiveau']. En effet, is_int('15') est égal à false. Il faut utiliser la fonction is_numeric()

    Exemple : tests de is_numeric()

    La fonction is_numeric() renvoie true lorsqu'on lui transmet en paramètre un nombre décimal (exemple : is_numeric(17.2) est égal à true). Or, nous attendons des entiers. Pour faciliter les tests, nous ajoutons la fonction estEntier() dans notre bibliothèque de fonctions. 

    /**
 * Teste si une valeur est une valeur entière
 *
 * @param   mixed    $x  valeur à tester
 *
 * @return  bool     true si entier, false sinon
 */
function estEntier(mixed $x):bool {
    return is_numeric($x) && ($x == (int) $x);
}
    Exemple : tests de estEntier()

    $_POST['radNiveau'] doit être compris entre 1 et 3, bornes incluses. D'où l'idée d'ajouter la fonction estEntre() dans notre bibliothèque de fonctions. 

    /**
 * Teste si un entier est compris entre 2 autres
 *
 * Les bornes $min et $max sont incluses.
 *
 * @param   int    $x  valeur à tester
 * @param   int    $min  valeur minimale
 * @param   int    $max  valeur maximale
 *
 * @return  bool   true si $min <= $x <= $max
 */
function estEntre(int $x, int $min, int $max):bool {
    return ($x >= $min) && ($x <= $max);
}

    Validation des zones de saisie libre

    La validation des textes saisis autres que des nombres est plus difficile, sauf si la chaîne doit obéir à un masque clairement identifié comme par exemple un code composé de 2 lettres majuscules, suivies d'un nombre à 3 chiffres, puis d'un tiret et de 3 lettres minuscules. Quand c'est possible, on essaiera de valider les chaînes saisies avec des expressions régulières (voir le chapitre qui leur est consacré).

    A défaut de pouvoir appliquer un masque de validation à une chaîne de caractères, les tests minimums vont consister à :

    • enlever les espaces blancs éventuels situés en début et en fin de chaîne en utilisant la fonction trim()
    • vérifier que la chaîne n'est pas vide (sauf si il est possible de ne rien saisir dans la zone)
    • si des limitations de longueur existent, vérifier que la chaîne est d'une longueur minimum et/ou maximum
    • enlever les tags HTML que l'utilisateur aurait pu glisser dans la chaîne pour protéger notre site contre les attaques XSS (cross-site scripting) en utilisant la fonction strip_tags()

    Dans notre formulaire d'exemple, il y a deux zones de saisie libre :

    • l'input de type text permettant la saisie du nom
    • et le textarea permettant la saisie des remarques

    Commençons par le nom en supposant qu'il doit être constitué de 2 à 50 caractères. 

    // test du nom
$nom = trim($_POST['txtNom']);
// c'est la longueur en nombre de caractères
// qui nous intéresse

require_once 'bib_fonctions.php';

/**
 * Fonction appelée quand une tentative de piratage est détectée
 *
 * Affiche un message et termine le script
 *
 * @return void
 */
function piratageDetecteExit() : void {
    echo '<p>Tentative de piratage ?</p>';

htmlDebut('Validation de toutes les zones');

// si soumission du formulaire
if (isset($_POST['btnEnvoi'])){
    if (! parametresControle('post',
            clesObligatoires:['btnEnvoi', 'hidSecret', 'txtNom',
                              'numIdentifiant', 'radNiveau',
                              'lstTP', 'txtRemarques'],
            clesFacultatives:['chkHtml', 'chkCss',
                              'chkJs', 'chkPhp'])){

        piratageDetecteExit(); //=> fin du script
    }
    // les clés sont valides

    // pour mémoriser les erreurs des utilisateurs "distraits"
    $errs = [];

    /* début du test des valeurs reçues une à une */

    // test de l'identifiant
    $id = $_POST['numIdentifiant'];
    if (estEntier($id)){
        if ($id <= 0){
            $errs[] = 'L\'identifiant doit être un entier strictement positif';
        }
    }
    else{
        $errs[] = 'L\'identifiant doit être un entier';
    }

    // test du niveau
    $niveau = $_POST['radNiveau'];
    if (! (estEntier($niveau) && estEntre($niveau, 1, 3))){
        piratageDetecteExit(); //=> fin du script
    }

    // test du nom
    $nom = trim($_POST['txtNom']);
    // c'est la longueur en nombre de caractères
    // qui nous intéresse
    $l = mb_strlen($nom, encoding:'UTF-8');
    if ($l < 2 || $l > 50) {
        $errs[] = 'Le nom doit contenir entre 2 et 50 caractères';
    }
    $noTags = strip_tags($nom);
    if ($noTags != $nom){
        $errs[] = 'Le nom ne doit pas contenir de tags HTML';
    }

    // test des remarques
    $rq = trim($_POST['txtRemarques']);
    $l = mb_strlen($rq, encoding:'UTF-8');
    if ($l > 255) {
        $errs[] = 'Le texte des remarques'.
                         ' ne doit pas contenir plus de 255 caractères';
    }
    $noTags = strip_tags($rq);
    if ($noTags != $rq){
        $errs[] = 'Le texte des remarques ne doit pas contenir de tags HTML';
    }

    // test de la liste déroulante
    if (! in_array($_POST['lstTP'],
                   ['A', 'B', 'C', 'indifférent'], true)){
        piratageDetecteExit(); //=> fin du script
    }

    // test des checkbox
    $tCheck = ['chkHtml', 'chkCss', 'chkJs', 'chkPhp'];
    foreach ($tCheck as $check){
        if (isset($_POST[$check])){
            if ($_POST[$check] !== '1'){
                piratageDetecteExit(); //=> fin du script
            }
        }
    }

    // test de l'input de type hidden
    if ($_POST['hidSecret'] !== 'pas vu'){
        piratageDetecteExit(); //=> fin du script
    }

    /* fin du test des valeurs reçues une à une */

    // affichage des résultats
    if (count($errs) > 0){
        echo '<p>Des erreurs ont été détectées :';
        foreach($errs as $err){
            echo '<br>- ', $err;
        }
        echo '</p>';
    }
    else {
        echo '<p>Ok, les données saisies sont valides.</p>';
    }
