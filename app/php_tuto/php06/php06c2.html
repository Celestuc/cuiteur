Une variable de session est une variable stockée dans un tableau superglobal de PHP, le tableau $_SESSION, et qui est disponible tout le temps que va durer la session. Elle sera accessible en lecture/écriture par tous les scripts d'une même session : tous les scripts déclenchés sur le même site par un même utilisateur et qui font appel à la fonction session_start().

    En réalité, session_start() permet de démarrer une nouvelle session ou de reprendre une session existante. Lors de son appel, PHP vérifie si une session existe dèjà (pour le client qui demande la page), c'est à dire si un identifiant de session (SID) lui a été affecté.

    • Si ce n'est pas le cas, session_start() démarre une nouvelle session, crée automatiquement un identifiant et l'affecte à la session. Dans ce cas, le script débute avec un tableau $_SESSION vide.
    • Sinon (i.e. un SID existe déjà), session_start() reprend la session existante, et le script débute avec un tableau $_SESSION contenant les données associées à ce SID (si ces données sont stockées dans un fichier, il est lu afin de les affecter dans $_SESSION).

    Lors de l'exécution du script, on peut ajouter / modifier / supprimer des données dans $_SESSION. Elles seront mémorisées dans le fichier associé au SID du client à la fin du script.

    Créer des variables

    Pour créer une variable de session, il suffit d'affecter une valeur à une clé dans le tableau superglobal $_SESSION.

    N'importe quel type de valeur pouvant être stockée dans un tableau peut être stocké dans $_SESSION, sauf les types ressources (pointeur sur un fichier, connexion à une base de données, etc).
