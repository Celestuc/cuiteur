La fonction fwrite() permet d'écrire du contenu dans un fichier.

Comme nous voulons ajouter du contenu à la fin du fichier, le fichier doit être ouvert (avec la fonction fopen()) en mode append : la valeur du paramètre spécifiant type d'opération ($mode) sera donc fixé à la valeur 'a'. Ainsi si le fichier n'existait pas, la fonction tenterait de le créer. Si le fichier peut être ouvert (ou créé), la fonction renvoie une variable de type resource représentant un flux (stream en anglais) associé au fichier physique.

Exemple : écrire dans un fichier

Le code du script lire_fichier.php est donné ci-dessous : 

<?php

error_reporting(E_ALL);

require_once 'bib_fonctions.php';

if (count($_GET) != 1){
    htmlDebut('Lecture d\'un fichier');
    htmlInfo('Seul un paramètre \'file\' doit être présent l\'URL');
    htmlFin();
    exit();
}


if (! isset($_GET['file'])){
    htmlDebut('Lecture d\'un fichier');
    htmlInfo('Pas de paramètre \'file\' dans l\'URL');
    htmlFin();
    exit();
}

$nom = $_GET['file'];

if (! is_file($nom)) {
    htmlDebut('Lecture d\'un fichier');
	htmlInfo("'$nom' n'existe pas ou n'est pas un fichier"
	           .' régulier');
	htmlFin();
	exit();
}

htmlDebut("Lecture du fichier '$nom'");

// Ouverture du fichier
$flux = @fopen($nom, 'r');
if ($flux === false){
	htmlInfo("Erreur lors de l'ouverture de '$nom'");
	htmlFin();
	exit();
}

echo '<pre>';
// boucle de lecture
while (true){
	$line = fgets($flux);
	if ($line === false){
		break;
	}
	echo htmlspecialchars($line, encoding:'UTF-8');
}
echo '</pre>';
// fermeture du flux
$r = fclose($flux);
if (! $r){
	htmlInfo('Erreur lors de la fermeture du flux');
	htmlFin();
	exit();
}

htmlFin();

Commentaires :

  • Le flux est ouvert en mode 'a+', c'est à dire en mode ajout en fin de fichier avec lecture. Le '+' signifie qu'il s'agit d'un mode 'a' (append) "augmenté" avec la possibilité manquante (écriture ou lecture). Comme avec le mode 'a', on peut uniquement écrire dans le fichier; l'ajout du '+' permet également de lire dans le fichier.
    Donc, dans ce mode :
    • si le fichier n'existe pas, il est créé;
    • toutes les écritures sont faites en fin de fichier (quelle que soit la valeur de l'offset);
    • les modifications de l'offset avec fseek() ou ou rewind() n'affectent que les lectures.
  • Si l'utilisateur saisit des sauts de ligne dans le textarea, ils sont remplacés dans le fichier par des tags HTML br afin que tous les enregistrements soient mémorisés sur une seule ligne dans le fichier, et que les sauts de ligne apparaissent quand on affiche les commentaires. La fonction affComment() permet d'assurer une protection contre les attaques XSS éventuellement présentes dans le champ de commentaires, sans neutraliser les tags HTML br.
