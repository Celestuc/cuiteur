PHP fournit seulement quelques fonctions pour traiter la gestion des dossiers. Nous devrons pallier les manques en écrivant nos propres fonctions, avec souvent le recours à la récursivité.

    Pour les exemples, nous utiliserons l'aborescence de dossiers ci-contre.

    Créer un dossier

    La création d'un dossier se fait avec la fonction mkdir(). 

    mkdir(string $directory, int $permissions = 0777,
	  bool $recursive = false): bool
    • La fonction renvoie true si la création a réussi, false sinon.
    • mkdir() accepte comme premier paramètre un chemin, relatif ou absolu, vers le (ou les) dossier(s) à créer;
    • mkdir() accepte un deuxième paramètre facultatif qui représente les permissions du (ou des) dossiers à créer (en notation octal comme sur les systèmes de type Unix);
    • Si le 3ème paramètre $recursive est égal à false, tous les répertoires du chemin fourni en premier paramètre doivent exister, sauf le dernier; sinon, la fonction mkdir() tente de créer l'ensemble des répertoires spécifiés dans le chemin à partir du premier répertoire préalablement inexistant.

    Supprimer un dossier

    La fonction rmdir() permet de supprimer un dossier à condition qu'il soit vide.

    • rmdir() accepte comme paramètre un chemin, relatif ou absolu, vers le (ou les) dossier(s) à supprimer.
    • rmdir() renvoie true si la suppression a réussi, false sinon.
    • Si le dossier n'est pas vide la suppression ne peut pas être faite.

    Le script suivant présente la fonction supprimerDossier qui supprime un dossier et son contenu éventuel. La fonction est récursive car le dossier peut contenir des dossiers qui peuvent contenir des sous-dossiers, qui eux-mêmes peuvent etc. 

    /**
 * Suppression d'un dossier et de son contenu
 *
 * @param string    $nom	Chemin vers le dossier à supprimer
 *
 * @return bool  	true si suppression effectuée
 */
function supprimerDossier(string $nom) : bool {
	if (!is_dir($nom)) {
		return false;
	}

	$ret = true;

  	//--- lecture du dossier 
  	$flux = @opendir($nom);
	while (($elem = readdir($flux)) !== false) {
		if ($elem == '.' || $elem == '..') {
			continue;
		}
		
		$complet = "$nom/$elem";
		if(is_dir($complet)) {
			$r = supprimerDossier($complet);
			if (! $r){
				$ret = false;
			}
		} else {
			$r = @unlink($complet);
			if (! $r){
				$ret = false;
			}
  		}
	}

	closedir($flux);

	if (! $ret){
		return false;
	}

	return @rmdir($nom);
}

    La fonction commence par tester si le chemin reçu en paramètre désigne un dossier existant. Si ce n'est pas le cas, elle arrête le traitement et renvoie false.
    Le dossier est ensuite lu comme vu précédemment. Pour chaque élément trouvé :

    • si c'est un dossier, la fonction supprimerDossier() est appelée (récursivité) pour supprimer le dossier et son contenu,
    • si c'est un fichier ordinaire, il est supprimé avec la fonction unlink()

    Quand tous les éléments du dossier ont été traité, la fonction renvoie le résultat de rmdir() appliqué sur le dossier courant.

    Copier un dossier

    PHP n'offre pas de fonction permettant de copier un dossier et il faut donc en écrire une. La fonction copierDossier() est récursive. La fonction accepte comme paramètres un chemin vers le dossier source, et un chemin vers le dossier destination (qui ne doit pas exister). Le traitement est le suivant :

    • création du dossier de destination
    • boucle de lecture du dossier source
    • si l'élément lu est un fichier : copie du fichier
    • si l'élément lu est un dossier : appel de la fonction de copie (récursivité)
    /**
 * Copie d'un dossier et de son contenu
 *
 * @param string    $src	Chemin vers le dossier source
 * @param string	$dest	Chemin vers le dossier destination
 *
 * @return int  	 0 : ok
 *                  -1 : erreur dossier source,
 *					-2 : erreur création répertoire
 *					-3 : erreur de copie de fichier ordinaire
 */
function copierDossier(string $src, string $dest) : int {
	if (!is_dir($src)) {
		return -1;	// Pas de dossier source, ou pas acccessible
	}
	
	if (! @mkdir($dest, recursive : true)) {
		return -2;	// Erreur création dossier destination
	}

	$ret = 0;
	
	// Lecture du dossier source
	$flux = @opendir($src);
	while (($elem = readdir($flux)) !== false) {
		if ($elem == '.' || $elem == '..') {
			continue;
		}
		$srcComplet = "$src/$elem";
		$destComplet = "$dest/$elem";

		if (is_dir($srcComplet)) {
			// Traitement récursif - sous-dossier
			$r = copierDossier($srcComplet, $destComplet);
			if ($r != 0){
				$ret = $r;
			}
		} else {
			// Copie d'un fichier
			$r = @copy($srcComplet, $destComplet);
			if (! $r){
				$ret = -3;
			}
		}
	}
	
	closedir($flux);
	
	return $ret;
}
