Le fait qu'on ne précise pas le type d'une variable lors de sa création ne veut pas dire qu'il n'y a pas de type de données dans PHP. PHP supporte huit types de données et offre de nombreuses fonctions permettant de connaître le type d'une variable et/ou de le changer.

    8 types de données dans PHP

    • 4 types scalaires : booléen, entier, nombre à virgule flottante, chaîne de caractères
    • 2 types composés : tableau et objet
    • 2 types spéciaux : ressource et null

    Type

    Remarque

    Exemple

    Booléen

    Valeurs possibles : TRUE FALSE

    $x = TRUE; 

    Entier

    Signés dont la taille dépend de la plate-forme. Valeurs possibles de -2 147 483 648 à +2 147 483 647 sur les systèmes 32 bits, ±9E18 sur les systèmes 64 bits

    $x = 12;
    $x = -123456;

    Virgule flottante

    IEEE 754 sur 64 bits, valeurs absolues possibles de 1.7E-308 à 1.7E+308

    $x = 1.2e-3;
    $x = -12345.78;

    Chaînes

    N'importe quelles valeurs entourées par des guillemets doubles ou simples

    $x = "françois piat";
    $x = 'is the best';

    Tableaux

    Un tableau PHP est une association ordonnée : des valeurs correspondent à des clés. Les clés peuvent être numériques et/ou alphabétiques. Les valeurs peuvent être de n'importe quel type.

    $x[0] = "françois";
    $x['nom'] = 'piat';
    $x[1] = 25;

    Objets

    Une classe est définie avec le mot-clé class et instanciée avec le mot-clé new.

    class Piat {
      function qui () {
        echo "François.";
      }
    }
    $x = new Piat;
    $x->qui();

    Ressource

    Une ressource est une référence sur l'extérieur (représentant par exemple un pointeur de fichier).

    $x = fopen("fic.txt", "r");

    null

    La valeur NULL représente une variable qui n'a pas de valeur.

    $x = NULL;
    $x = null;

    PHP fournit les mots-clés TRUE et FALSE pour travailler avec les booléens. Ces mots-clés ne sont pas sensibles aux majuscules et aux minuscules (true, True marchent aussi). Même si TRUE et FALSE ont respectivement les valeurs 1 et chaîne vide, utilisez TOUJOURS les mots-clés pour tester les valeurs booléennes ou pour assigner une valeur booléenne.

    PHP ne supporte pas les entiers non-signés. La taille d'un entier peut être déterminée en utilisant la constante PHP_INT_SIZE, la valeur maximale, en utilisant la constante PHP_INT_MAX, et la valeur minimale en utilisant la constante PHP_INT_MIN.

    La valeur spéciale NULL représente une variable sans valeur. NULL est la seule valeur possible du type null. La constante NULL est insensible à la casse.
    Une variable est considérée comme null si :

    • elle s'est vue assigner la constante null;
    • elle n'a pas encore reçu de valeur (i.e. elle n'est pas définie);
    • elle a été supprimée avec la fonction unset()

    Connaître le type d'une variable

    Nous pouvons connaître le type d'une variable en utilisant de nombreuses fonctions :

    • gettype() : retourne une chaîne décrivant le type de la variable ("boolean", "integer", "double", etc.)
    • is_bool() : retourne un booleén
    • is_int() : retourne un booleén
    • is_float() : retourne un booleén
    • is_string() : retourne un booleén
    • is_array() : retourne un booleén
    • is_object() : retourne un booleén
    • is_resource() : retourne un booleén
    • is_null() : retourne un booleén
    • is_scalar() : retourne un booleén. Les variables scalaires sont celles qui contiennent un entier, un nombre décimal, une chaîne de caractères ou un booléen. Les types array, object, resource et null ne sont pas scalaires.

    La fonction var_dump() , très utile pour débugguer un script, affiche les informations d'une variable, notamment son type et sa valeur.

    L'élément HTML pre (pour PREformatted text) permet de représenter du texte pré-formaté. Le texte contenu dans cet élément est généralement affiché dans une police à espacement fixe. Les "espaces blancs" (espaces, tabulations, sauts de ligne) contenus dans le texte sont affichés tels qu'ils sont dans le code source du document.

    Savoir si une variable existe

    Nous avons déjà constaté à plusieurs reprises que les tentatives d'accès à des variables non définies, supprimées, ou hors de portée déclenchent une erreur de type warning "Variable non définie".

    La fonction isset() détermine si une variable est définie. Plus précisément, elle renvoie TRUE si et seulement si la variable passée en paramètre est définie ET si elle est différente de null.
    Intérêt de cette fonction : elle ne génère pas de warning si on lui transmet une variable qui n'existe pas.

    En réalité, isset() n'est pas vraiment une fonction : il s'agit d'une construction du langage.

    Exemple : la fonction isset()

    La fonction isset() nous sera très utile pour tester si un paramètre est transmis dans une URL, et lors du traitement des données soumises par un formulaire.

    Savoir si une variable est numérique

    La fonction is_numeric() détermine si une variable est un nombre (entier ou réel) ou une chaine numérique. Elle retourne true si c'est le cas, false sinon.

    Une chaîne numérique est une chaîne contenant uniquement des caractères valides pour représenter un nombre (entier ou réel), avec éventuellement des espaces blancs (caractère espace, tabulation "\t", saut de ligne "\n", etc.) en début et en fin de chaîne.

    Exemple : la fonction is_numeric()

    La fonction is_numeric() est utilisée pour tester les valeurs des paramètres transmis dans une URL et les données saisies dans un formulaire, car ces valeurs sont toutes reçues par PHP dans des chaînes de caractères.
