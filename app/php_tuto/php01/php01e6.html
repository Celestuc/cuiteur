Avec PHP, il est possible d'appeler une fonction via une variable qui contient son nom. Si le nom d'une variable est suivi de parenthèses, PHP recherchera si une fonction de nom égal à la valeur de la variable existe. Si c'est le cas la fonction est appelée. Si aucune fonction n'est trouvée une erreur est générée.

    Considérons l'exemple suivant :

    switch ($quoiFaire) {
case 'ajouter' :
  ajouter();
  break;
case 'supprimer' :
  supprimer();
  break;
case 'modifier' :
  modifier();
  break;
default :
  interdit();
}

    Ce type de code est souvent fréquemment utilisé dans les pages d'index de site, ou dans le modèle de conception MVC (Model-View-Controller).

    Nous pouvons utiliser une fonction variable à la place de ce code et le remplacer tout simplement par $quoiFaire();.
    Si la variable $quoiFaire contient 'ajouter', la fonction ajouter() est invoquée ; si la variable contient 'supprimer', la fonction supprimer() est invoquée ; si la variable contient 'modifier', la fonction modifier() est invoquée.

    Nous avons un problème si $quoiFaire contient autre chose que 'ajouter', 'supprimer' ou 'modifier', car nous allons appeler une fonction dont le nom peut être n'importe quoi. Mais PHP nous donne la solution avec la fonction function_exists() qui permet de savoir si une fonction est définie ou non : 

    if (function_exists($quoiFaire) {
  $quoiFaire();
} else {
  interdit();
}

    Nous pouvons aussi utiliser l'opérateur ternaire :

    function_exists($quoiFaire) ? $quoiFaire() : interdit();
