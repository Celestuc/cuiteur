Boucle avec while

    while (condition) {
	instruction;
	...
}

    while exécute la commande ou le bloc de commandes tant que la condition est évalue comme true.

    L'instruction break permet de forcer la sortie d'une boucle, en passant à l'instruction qui la suit.
    Dans le cas de boucles imbriquées, break permet de sortir de la boucle la plus interne, ou si elle est suivie d'un nombre optionnel  i  de la  ième  boucle la plus interne.

    L'instruction continue permet de passer à l’itération suivante de la boucle la plus interne sans effectuer la fin des traitements pour l’itération en cours.
    Dans le cas de boucles imbriquées, continue peut être suivi d'un nombre entier qui indique combien de boucles emboîtées doivent être éludées.

    PHP supporte aussi les boucles do ... while avec la syntaxe : 

    do {
	instruction;
	...
} while (condition);

    Boucle avec for

    for (expression_1; expression_2; expression_3) {
	instruction_1;
	...
	instruction_N;
}

    est équivalente à la structure suivante, à condition que les instructions à répéter ne contiennent pas d’appel à l'instruction continue. 

    expression_1;
while ( expression_2) {
	instruction_1;
	...
	instruction_N;
	expression_3;
}

    Dans les parenthèses qui suivent le mot clé for, il y a trois expressions séparées par des points virgule :

    • expression_1 est tout d’abord évaluée ou exécutée (notez bien qu’elle n’est exécutée qu’une seule fois avant en quelque sorte l’entrée dans la boucle). Cette expression initialise en général une variable utilisée comme compteur dans la boucle ;
    • expression_2 joue le rôle de condition logique. Elle conditionne la poursuite de la boucle. Elle est évaluée avant chaque exécution du bloc de traitement ;
    • expression_3 est évaluée ou exécutée après les instructions contenues dans le bloc de traitement à la fin de chaque itération. Elle sert en général à mettre à jour la variable utilisée comme compteur dans la boucle.
    Exemple : boucle for

    Plusieurs expressions peuvent être définies dans expression_1, expression_2 et expression_3. Il suffit de les séparer par des virgules : 

    for ($i = 0, $j = 10; $i > 10, $j > 50; $i++, $j *= 2) {
	...
}

    Boucle avec foreach

    L'instruction foreach permet de faire des itérations sur un tableau. Cette instruction est particulièrement utile dans PHP où les tableaux peuvent avoir des clés alphanumériques (table de hachage ou dictionnaire) ou bien des indices numériques non consécutifs.

    Un chapitre entier est consacré à l'utilisation des tableaux dans PHP et vous y trouverez toutes les informations détaillées sur la façon de réaliser des itérations.

    L'instruction foreach définit une boucle exécutée automatiquement du premier au dernier élément d'un tableau. On ne peut donc pas choisir ni le premier élément "parcouru", ni l'élément de fin (à moins de sortir de la boucle avec une instruction break).

    On présente ici les 2 syntaxes permettant d'accéder en consultation aux éléments d'un tableau.

    foreach ($tableau as $valeur) {
	instruction
	...
}

    Avec cette première syntaxe (ci-dessus), à chaque itération la valeur de l'élément courant du tableau $tableau est affectée dans la variable $valeur. Tous les éléments du tableau sont parcourus, du premier au dernier. 

    foreach ($tableau as $cle => $valeur) {
	instruction
	...
}

    Avec cette seconde syntaxe (ci-dessus), en plus de la valeur de l'élément courant affectée dans la variable $valeur, la valeur de la clé de l'élément est affectée dans la variable $cle.
