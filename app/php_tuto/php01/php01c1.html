Les opérateurs prennent des valeurs (les opérandes) et réalisent des opérations avec elles.
    Beaucoup d'opérateurs attendent des types de données particuliers. Par exemple les opérateurs arithmétiques attendent des nombres. Si les opérandes ne sont pas des types attendus, PHP prend en charge automatiquement les conversions de types (type juggling).

    Opérateurs de transtypage

    Bien que PHP soit un langage sans déclaration du type des variables, des opérateurs permettent de convertir la valeur d'une variable dans un type cible

    •  (int)  ou  (integer)  : le résultat est un entier.
    •  (float)  ou  (real)  : le résultat est nombre à virgule flottante.
    •  (string)  : le résultat est une chaîne de caractères.
    •  (bool)  ou  (boolean)  : le résultat est un booléen.
    •  (array)  : le résultat est un tableau.
    •  (object)  : le résultat est un objet.

    Pour convertir une variable dans un type cible, nous pouvons également utiliser la fonction settype().

    Toutes les conversions ne sont pas possibles ou utiles. Exemples :

    • Transformer un objet en string déclenche une erreur fatale qui arrête le script
    • Transtyper un tableau en string donne la chaîne  Array  et déclenche une erreur de type warning
    • Transtyper un tableau en entier donne comme résultat  0  si le tableau est vide, et  1  s'il contient au moins un élément
    • Transtyper un objet en entier donne comme résultat  1 , et déclenche une erreur de type warning

    Transformer un objet en tableau donne un tableau associatif : nom de propriété associé à la valeur de la propriété.

    Transformer un tableau en objet donnera un objet dont les propriétés auront pour noms les clés du tableau, et pour valeurs, les valeurs du tableau.

    Exemple : opérateurs de type

    Conversion des chaînes en nombre :

    • les éventuels espaces blancs en début de chaîne sont ignorés
    • ensuite, tous les caractères valides (chiffres, caractère . (point), caractère e ou E, etc.), situés en début de chaine, sont utilisés pour former une valeur numérique, qui est pour finir convertie en réel ou en entier.
    • le parcours de la chaîne est arrêté dès qu'un caractère non valide est rencontré
    • si le premier caractère de la chaîne (différent d'un espace blanc) n'est pas valide, le résultat est 0

    Le résultat de la conversion d'un réel en entier est égal à la partie entière du nombre réel.

    Evaluation booléenne des variables

    Lors d'une conversion en booléen, seules les valeurs suivantes sont considérées comme FALSE :

    • le booléen false, lui-même
    • l'entier 0 (zéro)
    • le nombre à virgule flottante 0.0(zéro)
    • la chaîne vide '', et la chaîne "0"
    • un tableau vide, i.e. sans aucun élément
    • le type spécial NULL
    • un objet SimpleXML créé depuis un élément sans enfant et sans attribut

    Toutes les autres valeurs sont considérées comme TRUE.

    Exemple : Evaluation booléenne

    Une variable non définie est évaluée à false, mais le fait de tenter d'y accéder déclenche une erreur de type warning.

    Les opérateurs arithmétiques

    • + : addition
    • - : soustraction
    • * : multiplication
    • / : division
    • % : modulo (reste d'une division)

    Les opérateurs arithmétiques attendent normalement des nombres (entiers ou réels (i.e. nombre à virgule flottante)). Les régles de conversion automatique (type juggling) suivantes sont appliquées :

    Premier opérande Second opérande Conversion automatique Résultat
    Entier Entier Aucune Entier (sauf pour les divisions où le résultat peut être un réel)
    Réel Réel Aucune Réel
    Entier Réel L'entier est converti en un réel. Réel.
    Entier Chaîne La chaîne est convertie en un nombre. Si ce nombre est un réel, l'entier est converti en réel. Entier ou réel.
    Réel Chaîne La chaîne est convertie en un nombre réel. Réel.
    Chaîne Chaîne Les chaînes sont converties en nombres. Si un des nombres est un entier et l'autre est un réel, l'entier est converti en réel. Entier ou réel.
    Exemple : opérateurs arithmétiques et transtypage automatique
    • si la chaine est numérique (i.e. is_numeric() renverrait true), la conversion automatique en nombre se passe bien (i.e. sans déclencher d'erreur de type warning)
    • sinon si la chaîne commence par des caractères valides pour former un nombre (mais possède ensuite au moins un caractère non valide), une erreur de type warning est déclenchée.
    • sinon une erreur fatale qui arrête le script est déclenchée

    Conclusions :

    • avant d'utiliser un opérateur arithmétique, si on veut être certain qu'aucune erreur ne soit déclenchée, il faut toujours s'assurer que les deux opérandes sont soit des nombres, soit des chaînes numériques (cf. is_numeric()).
    • si vous transtypez la chaîne en nombre entier ou réel avant l'application de l'opérateur arithmétique, il n'y a plus d'erreur possible.

    La fonction intdiv() permet de réaliser des divisions entières.

    Concaténation de chaînes

    La concaténation de chaînes se fait avec l'opérateur . (point). Si nécessaire, les opérandes sont convertis automatiquement en chaînes.

    Les chaînes peuvent être entourées de guillemets simples ou doubles. PHP traîtera différemment les chaînes suivant le type des guillemets :

    • si la chaîne est entourée de guillemets simples, elle est évaluée tel quelle.
    • si la chaîne est entourée de guillemets doubles, les variables éventuelles contenues dans la chaîne seront remplacées par leur valeur.

    Je vous conseille d'utiliser des guillemets simples si vous n'avez pas de substitutions de variables dans vos chaînes. De cette façon, PHP n'examinera pas la chaîne pour savoir si elle contient des variables à remplacer par leur valeur. Vous aurez beaucoup plus d'informations sur le sujet dans le chapitre consacré aux chaînes de caractères.

    Incrémentation et décrémentation

    Les opérateurs d'autoincrément et d'autodécrément ne sont applicables qu'à des variables numériques ou alphanumériques.

    Opérateur Syntaxe   Résultat sur la variable Valeur de l'expression
     ++   $x++  post incrémention  $x = $x + 1  Valeur initiale de  $x 
     ++$x  pré incrémentation  $x = $x + 1  Valeur finale de  $x 
     --   $x--  post décrémentation  $x = $x - 1  Valeur initiale de  $x 
     --$x  pré décrémentation  $x = $x - 1  Valeur finale de  $x 

    L'incrémentation d'une variable consiste à modifier sa valeur en lui ajoutant 1.
    Dans le cas d'une pré incrémentation ( ++$x ), la variable est d'abord incrémentée, puis l'expression est évaluée.
    Dans le cas d'une post incrémentation ( $x++ ), c'est l'inverse, l'expression est d'abord évaluée , puis la variable est incrémentée.

    Opérateurs d'affectation

    Ces opérateurs donnent une valeur, ou modifient la valeur d'une variable. L'affectation peut être simple ou combinée avec une opération.

    •  =  : une valeur est affectée.

      $x = 10; $x contient la valeur 10
      $x = $y = 10; $y contient la valeur 10 puis la valeur de $y est affectée à $x
      $x = $y + $z; $x contient le résultat de l'addition de $y et $z

    •  .=  : concaténation de chaînes de caractères. L'opérande de droite est ajouté à la suite de l'opérande de gauche qui reçoit le résultat.

      $x = 'François';
      $x .= ' Piat';
      $x contient 'François Piat'

    •  +=  : ajoute l'opérande de droite à l'opérande de gauche qui reçoit le résultat.

      $x += 5 est identique à $x = $x + 5

    •  -=  : soustrait l'opérande de droite de l'opérande de gauche qui reçoit le résultat.

      $x -= 5 est identique à $x = $x - 5

    •  /=  : divise l'opérande de gauche par l'opérande de droite, puis assigne le résultat à l'opérande de gauche.

      $x /= 5 est identique à $x = $x / 5

    •  *=  : multiplie l'opérande de gauche par l'opérande de droite, puis assigne le résultat à l'opérande de gauche.

      $x *= 5 est identique à $x = $x * 5

    •  %=  : divise (division entière) l'opérande de gauche par l'opérande de droite, puis assigne le reste de la divison à l'opérande de gauche.

      $x %= 5 est identique à $x = $x % 5

    •  ^=  : opération bit à bit bit XOR sur les opérandes. Le résultat est affecté à l'opérande de gauche.
    •  &=  : opération bit à bit AND sur les opérandes. Le résultat est affecté à l'opérande de gauche.
    •  |=  : opération bit à bit bit OU sur les opérandes. Le résultat est affecté à l'opérande de gauche.
    Exemple : opérateurs d'assignement

    Opérateurs bit à bit

    Ces opérateurs travaillent sur la représentation binaire des opérandes.

    •  $a & $b  : AND (les bits positionnés à 1 dans $a ET dans $b sont positionnés à 1).
    •  $a | $b  : OR (les bits positionnés à 1 dans $a OU inclusif dans $b sont sont positionnés à 1).
    •  $a ^ $b  : XOR (les bits positionnés à 1 dans $a OU exclusif dans $b sont positionnés à 1).
    •  ~ $a  : NOT (les bits qui sont positionnés à 1 dans $a sont positionnés à 0, et vice versa).
    •  $a << $b  : décale les bits de $a, $b fois sur la gauche (chaque décalage équivaut à une multiplication par 2).
    •  $a >> $b  : décale les bits de $a, $b fois sur la droite (chaque décalage équivaut à une division par 2).

    Opérateurs de comparaison

    Ces opérateurs comparent des opérandes de n'importe quel type et renvoient la valeur true ou la valeur false.

    Les opérateurs de comparaisons strictes === et !== ne réalisent jamais de conversion automatique de type.

    Les opérateurs de comparaison stricte
    Opérateur Nom TRUE si et seulement si
    === Identité les opérandes sont du même type et ont la même valeur
    !== Non Identité les opérandes ne sont pas du même type ou ont une valeur différente
    Exemple : opérateur de comparaison stricte

    Les opérateurs de comparaisons non strictes (ou larges) ==, !=, <>, <, >, <= et >= réalisent des conversions automatiques de type (type juggling) si besoin, notamment si les opérandes ne sont pas du même type.

    Les opérateurs de comparaison non stricte
    Opérateur Nom TRUE si et seulement si
    == Egalité les opérandes ont la même valeur, après le transtypage
    != ou <> Non égalité les opérandes n'ont pas la même valeur, après le transtypage
    < Plus petit le premier opérande est strictement plus petit que le second, après le transtypage
    > Plus grand le premier opérande est strictement plus grand que le second, après le transtypage
    <= Plus petit ou égal le premier opérande est plus petit ou égal au second, après le transtypage
    >= Plus grand ou égal le premier opérande est plus grand ou égal au second, après le transtypage

    Règles appliquées en PHP 8 quand on compare (avec des opérateurs de comparaison non stricte) des booléens, des chaînes ou des nombres :

    • si un des opérandes est un booléen, alors une comparaison booléenne est effectuée (l’autre opérande est converti en booléen si besoin)
    • sinon si les deux opérandes sont des nombres ou des chaînes numériques (i.e. is_numeric() renverrait true), alors une une comparaison numérique est effectuée (les chaînes numériques sont converties en nombre, et les entiers en réels si besoin)
    • sinon une une comparaison lexicographique est effectuée (conversion d'un des opérandes en chaîne si besoin)
    Exemple : opérateur de comparaison non stricte

    Comme vous pouvez le remarquer certaines égalités peuvent sembler étranges quand on est habitué à travailler avec des langages fortement typés.
    On notera par exemple que la chaîne 'true' est égale au booléen true, mais que la chaîne 'false' n'est pas égale au booléen false.

    Conclusion : soyez attentif quand vous faites des tests aux transtypages automatiques qui sont faits par PHP pour comparer des valeurs.
    Si vous voulez faire des tests "forts", utilisez les opérateurs de comparaisons strictes.

    Opérateurs logiques

    •  AND  ou  &&  : le résultat est true si et seulement si les 2 opérandes sont évalués à true.
      Opérandes Résultat
       A   B   A && B 
       false   false   false 
       false   true   false 
       true   false   false 
       true   true   true 

      Dans $r = $a AND $b $r sera égal à true si et seulement si $a ET $b sont évalués comme true.

      Dans if ( $a == 0 && $b > 1) ... le test sera vrai si et seulement si $a est égal à 0 ET $b est supérieur à 1.

      Si l'opérande de gauche est évalué à false, le résultat est forcément égale à false : l'évaluation de l'opérande de droite n'est pas nécessaire, et donc l'opérande de droite n'est pas évaluée. On dit que les opérateurs  AND  et  &&  sont "paresseux".

    •  OR  ou  ||  : le résultat est true si et seulement si un des 2 opérandes est évalué comme true.
      Opérandes Résultat
       A   B   A || B 
       false   false   false 
       false   true   true 
       true   false   true 
       true   true   true 

      Dans $r = $a OR $b $r sera égal à true si et seulement si $a est évalué comme true, OU $b est évalué comme true.

      Dans if ( $a == 0 || $b > 1) ... le test sera vrai si et seulement si $a est égal à 0 OU $b est supérieur à 1.

      Si l'opérande de gauche est évalué à true, le résultat est forcément égale à true : l'évaluation de l'opérande de droite n'est pas nécessaire, et donc l'opérande de droite n'est pas évaluée. Comme les opérateurs  AND  et  && , les opérateurs  OR  et  ||  sont dits "paresseux".

    •  XOR  : le résultat est true si et seulement si un seul des deux opérandes est évalué comme true.
      Opérandes Résultat
       A   B   A XOR B 
       false   false   false 
       false   true   true 
       true   false   true 
       true   true   false 
    •  !  : négation (le résultat est true si et seulement si l'opérande est évalué comme false).
      • Opérande Résultat
       A   ! A 
       false   true 
       true   false 
    Exemple : opérateurs logiques

    Autres opérateurs

    •  @  : lorsque cet opérateur de contrôle d'erreur est ajouté en préfixe d'une expression PHP, ou d'un appel de fonction, les éventuels messages d'erreur générés sont supprimés.
    •  ? :  : opérateur conditionnel ou ternaire.
      Cet opérateur prend 3 opérandes :
      expr1 ? expr2 : expr3
      Il évalue son premier opérande expr1 qui joue le rôle d’une condition logique.
      • si expr1 est évaluée à true, il y a évaluation du second opérande expr2, ce qui fournit le résultat.
      • sinon, il y a évaluation du troisième opérande expr3, ce qui fournit le résultat.

      Exemples :

      •  $c = ($a > $b) ? $a : $b; 
        affecte dans  $c  la valeur de  $a  si  $a > $b  est vrai. Dans le cas contraire, la valeur de  $b  est affectée dans  $c .
      •  ($a > $b) ? $i++ : $i--; 
        Ici, suivant que la condition  $a > $b  est vraie ou fausse, on incrémentera ou on décrémentera la variable  $i . Notez que dans cet exemple, la valeur de l'expression ternaire n'est pas utilisée.
